# RAG 轻量评测

该目录用于对比以下三种检索方案：

1. 纯向量检索
2. 向量检索 + 中文 BM25 + RRF
3. Rewrite + 混合检索 + LLM 精排

评测集包含 30 道题，其中 25 道有答案、5 道无答案。题目覆盖直接事实、关键词、语义表达和上下文追问。

## 运行

先安装项目依赖并配置 `DASHSCOPE_API_KEY`，然后在项目根目录执行：

```bash
python evaluation/run_retrieval_eval.py
```

输出文件位于 `evaluation/results/`：

- `report.md`：适合直接阅读的量化报告
- `summary.json`：各方案汇总指标
- `retrieval_details.csv`：逐题检索结果，可使用 Excel 检查

## 指标说明

- **Top-4 命中率**：前 4 个结果中是否存在人工标注的正确证据 Chunk。
- **MRR@4**：正确证据排名越靠前，分数越高；未进入前 4 记为 0。
- **无答案拒答率**：资料中没有答案时，精排是否过滤掉全部候选。
- **延迟**：只统计检索链路，不包含最终答案生成。

该评测用于个人项目的方案对比，不代表生产环境效果。
